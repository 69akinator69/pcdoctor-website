1 Les Fondations : Exigences Matérielles Strictes

Contrairement à ses prédécesseurs, Windows 11 impose des exigences de sécurité renforcée au niveau matériel. Il ne s'agit pas de simples recommandations de confort, mais de conditions bloquantes vérifiées dès le démarrage par le programme d'installation Microsoft.

Composant Exigence Minimale Requise Recommandation Professionnelle PC Doctor Conséquence si Non Conforme
Processeur (CPU) 1 GHz+, 2 cœurs minimum, architecture 64 bits ou SoC Intel Core 8e génération min. (i5-8250U, i5-8400, etc.) ou AMD Ryzen 2000/3000+ Blocage d'installation officiel ("Ce PC ne peut pas exécuter W11")
TPM (Module de Plateforme Sécurisée) Version 2.0 obligatoire (dTPM puce dédiée ou fTPM/PTT micrologiciel) Puce TPM 2.0 active dans le micrologiciel de la carte mère (Intel PTT / AMD fTPM) Impossible de démarrer l'installation sans contournement registre
Micrologiciel & Démarrage Mode UEFI avec prise en charge du démarrage sécurisé (Secure Boot) UEFI natif actif avec table de partitionnement GPT (Style GUID) Refus d'installation sur disques formatés en MBR (Master Boot Record)
Mémoire Vive (RAM) 4 Go de mémoire physique 8 Go à 16 Go DDR4 / DDR5 pour une réactivité optimale du système Ralentissements sévères et gel pendant le multitâche
Stockage Système 64 Go d'espace disponible minimum SSD NVMe M.2 ou SSD SATA de 256 Go minimum Échec de mise à jour future faute d'espace disque disponible
Carte Graphique & Écran DirectX 12 ou ultérieur avec pilote WDDM 2.0 ; écran HD 720p 9" Écran Full HD (1080p) avec GPU intégré moderne ou dédié Affichage dégradé ou absence d'accélération matérielle
Pourquoi Microsoft impose-t-il le TPM 2.0 et l'UEFI ?
Le module Trusted Platform Module 2.0 est un coffre-fort cryptographique matériel soudé sur la carte mère ou intégré au processeur. Il stocke les clés de chiffrement (BitLocker), gère l'authentification biométrique sans mot de passe Windows Hello, et contrôle l'intégrité de la séquence de démarrage contre les rootkits avant même que Windows ne prenne la main.

3 Stratégie : Les 3 Méthodes de Déploiement

Avant d'insérer un média externe, le technicien doit choisir la méthode appropriée selon l'état actuel de la machine, la présence de logiciels métier ou de virus, et l'objectif de conservation des fichiers.

Méthode N°1

Mise à Niveau Windows Update

La solution directe pour un poste sous Windows 10 fonctionnel et compatible.

  • Conserve les fichiers : Oui, intégrale (profils, logiciels, favoris).
  • Condition : Windows 10 version 2004 ou supérieure activé.
  • Espace requis : Au moins 64 Go d'espace libre sur le disque C:.
  • Processus : Téléchargement en arrière-plan puis redémarrages.
Idéal pour utilisateur particulier
Méthode N°2

Assistant d'Installation Windows 11

Outil autonome exécutable sur une machine compatible si Windows Update tarde.

  • Conserve les fichiers : Oui, conservation paramétrable.
  • Usage : Force le déploiement immédiat de la dernière version (24H2/26H2).
  • Limitation : Ne fonctionne que sur architecture x64 (non compatible ARM direct).
  • Fichier source : Téléchargeable sur microsoft.com.
Idéal pour mise à niveau rapide
Méthode N°3 • Recommandée PC Doctor

Installation Propre via Clé USB

Le standard des professionnels : remise à zéro complète, formatage et partitionnement propre.

  • Conserve les fichiers : Non (suppression complète des anciennes partitions).
  • Avantage : Élimine 100% des malwares, scories et erreurs de registre accumulées.
  • Polyvalence : Fonctionne sur disque SSD neuf vierge ou machine bloquée.
  • Outil : Clé USB bootable créée avec Media Creation Tool.
Gold Standard des Techniciens

4 Préparation du Support : Création de la Clé USB Bootable

Pour installer Windows 11 de zéro, nous créons un média d'installation externe autonome (mémoire flash USB).

AVERTISSEMENT MATÉRIEL IMPORTANT :
La clé USB utilisée doit disposer d'une capacité minimale de 8 Go. Toutes les données présentes sur cette clé seront définitivement effacées lors de la création du support de démarrage. Sauvegardez son contenu au préalable.

Procédure Officielle avec le Media Creation Tool

  1. Munissez-vous d'un ordinateur sous Windows connecté à Internet et branchez la clé USB de 8 Go minimum.
  2. Rendez-vous sur le site officiel Microsoft dans la section Téléchargement de logiciels > Télécharger Windows 11.
  3. Dans la rubrique Création d'un support d'installation de Windows 11, cliquez sur Télécharger pour obtenir l'exécutable officiel.
  4. Exécutez le fichier téléchargé en tant qu'administrateur et acceptez les termes du contrat de licence.
  5. Sur la page Sélection de la langue et de l'édition, laissez cochée la case "Utiliser les options recommandées pour ce PC" (ou choisissez le Français et l'édition 64-bit).
  6. À l'écran "Choisissez le média à utiliser", sélectionnez Disque mémoire flash USB.
  7. Sélectionnez la clé USB cible dans la liste des lecteurs amovibles, puis cliquez sur Suivant.
  8. L'utilitaire télécharge l'image système Windows 11 puis écrit les fichiers d'amorçage UEFI sur la clé. À la fin, le message "Votre disque mémoire flash USB est prêt" apparaît. Cliquez sur Terminer.

Alternative : Vérification de l'Empreinte de l'Image ISO via PowerShell

Si vous téléchargez directement l'image ISO multi-édition pour l'intégrer à un serveur PXE ou une clé multiboot, contrôlez toujours son intégrité cryptographique pour éviter toute altération.

# Commande de calcul du hachage SHA-256 sous PowerShell : Get-FileHash -Path "C:\Users\Admin\Downloads\Win11_26H2_French_x64.iso" -Algorithm SHA256 # Empreinte SHA256 officielle Microsoft (Version Française 64-bit) : # AA515279F02FB2B425EFF341F0A1F158D61288C72CCA5F9D87B79B5A23F7F918

5 Démarrer sur la Clé : Les Touches Boot Menu par Constructeur

Lorsque l'on allume un ordinateur, celui-ci démarre par défaut sur son disque dur interne. Pour forcer l'ordinateur à démarrer sur votre clé USB d'installation, vous devez déclencher le Menu de Démarrage (Boot Menu) dès la mise sous tension.

Sélecteur de Procédure Constructeur

Choisissez la marque de votre ordinateur :

PC Portables & Bureaux DELL (Latitude, OptiPlex, Precision, Vostro)

TOUCHE : F12
  1. Éteignez complètement l'ordinateur (pas de veille prolongée).
  2. Branchez la clé USB bootable sur un port USB direct (évitez les hubs non alimentés).
  3. Allumez la machine et tapotez immédiatement et rapidement la touche F12 du clavier sans interruption jusqu'à l'apparition de l'écran One-Time Boot Menu.
  4. À l'aide des flèches directionnelles, descendez dans la section UEFI BOOT.
  5. Sélectionnez votre clé USB (ex: UEFI: SanDisk Ultra USB 3.0) et appuyez sur la touche ENTRÉE.

7 Diagnostic des Pannes : Résolution des Erreurs Fréquentes

Durant les déploiements, les techniciens sont fréquemment confrontés à des blocages matériels ou des refus d'installation. Voici les 5 scénarios d'incidents les plus fréquents et leur protocole de résolution.

Module de Diagnostic Interactif

Sélectionnez le symptôme rencontré lors de l'installation :

Erreur : "Ce PC ne répond pas actuellement à la configuration requise"

Cause Racine : Le module TPM 2.0 est désactivé dans le BIOS/UEFI, ou le mode Démarrage Sécurisé (Secure Boot) est inactif, ou le processeur est de génération antérieure à Intel Gen 8 / AMD Zen 2.

Protocole de Résolution PC Doctor :
  1. Redémarrez le PC et entrez dans le BIOS Setup (Touche F2 ou Suppr).
  2. Allez dans l'onglet Security > Activez Intel PTT (Platform Trust Technology) ou AMD fTPM.
  3. Allez dans l'onglet Boot > Activez Secure Boot et passez en mode UEFI (désactivez le mode Legacy/CSM).
  4. Sauvegardez en appuyant sur F10 et relancez l'installation.

8 Protocole Post-Installation & Check-list Technique

Une fois l'écran d'accueil Windows 11 affiché, le travail du technicien n'est pas terminé. Pour livrer une machine stable et performante, cochez chaque étape du protocole de conformité :

Contrôle Qualité de Sortie d'Atelier : Progression : 0 / 6 Validés
1. Mises à Jour Complètes Windows Update : Accéder aux Paramètres > Windows Update > "Rechercher des mises à jour" et répéter l'opération jusqu'à ce que le système indique "Vous êtes à jour".
2. Pilotes Graphiques Constructeur Dédiés : Installer l'utilitaire constructeur officiel pour carte graphique (NVIDIA GeForce Experience ou AMD Radeon Software) afin d'assurer l'accélération matérielle et le bon taux de rafraîchissement.
3. Vérification du Gestionnaire de Périphériques : Exécuter devmgmt.msc et s'assurer qu'aucun point d'exclamation jaune ou "Périphérique inconnu" ne subsiste (notamment chipset, Wi-Fi et Bluetooth).
4. Vérification de l'Activation Numérique : Contrôler dans Paramètres > Système > Activation que la mention "Actif" est bien présente.
5. Sécurité & Antivirus Windows Defender : Vérifier que la protection en temps réel, l'isolation du noyau (Core Isolation) et la sécurité basée sur la virtualisation (VBS) sont opérationnelles.
6. Nettoyage des Fichiers Temporaires d'Installation : Lancer l'outil Nettoyage de disque (cleanmgr) pour purger les fichiers d'installation résiduels et l'éventuel dossier Windows.old afin de libérer 15 à 25 Go de stockage.
