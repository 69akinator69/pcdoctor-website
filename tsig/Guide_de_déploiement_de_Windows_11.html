Déploiement de Windows 11 : de l'Hyperviseur à l'Écran d'Accueil

Maîtrisez l'ingénierie de déploiement de Windows 11 Professionnel. Découvrez les réglages critiques de firmware UEFI, l'émulation TPM 2.0, les contournements du registre (LabConfig), le bypass de compte Microsoft (OOBE\BYPASSNRO), ainsi que la paravirtualisation par les Guest Additions et la préparation d'un poste physique via clé USB.

CHAPITRES :
MODULE 01

Création de l'Enceinte Virtuelle : VirtualBox 7.0+

Dans une architecture de virtualisation de Type-2 (où l'hyperviseur s'exécute sur un système d'exploitation hôte préexistant comme Windows 10/11 ou Linux), le déploiement de Windows 11 exige une rigueur méticuleuse. Contrairement aux versions précédentes de Windows, l'installeur applique des contrôles matériels bloquants dès les premières secondes de chargement.

Paramètres d'identification de la machine virtuelle

  • Nom explicite : Définir une convention claire telle que VM-WIN11-PRO ou LAB-W11-X64.
  • Emplacement physique : Sélectionner impérativement un répertoire situé sur une partition SSD NVMe afin de prévenir tout goulot d'étranglement lors des phases d'E/S intenses.
  • Image ISO : Sélectionner le fichier officiel de Microsoft (taille moyenne : ~5,2 Go). VirtualBox détectera automatiquement le type Microsoft Windows et la version Windows 11 (64-bit).
RÈGLE CRITIQUE D'INGÉNIERIE : Skip Unattended Installation

Lors de l'étape de sélection de l'ISO, VirtualBox active par défaut un mécanisme d'installation automatisée (Unattended). Vous devez impérativement cocher la case « Ignorer l'installation sans assistance » (Skip Unattended Installation). Si vous négligez cette option, l'hyperviseur force des identifiants génériques, écrase le partitionnement et interdit tout paramétrage granulaire des comptes locaux et du réseau.

ARCHITECTURE DU DISQUE VIRTUEL

VDI : Dynamique vs Fixe

Un disque de 80 Go est dimensionné pour accueillir le système d'exploitation (~25 Go), les mises à jour cumulatives et les bibliothèques d'outils d'administration.

Allocation Dynamique (Recommandée) : Le fichier .vdi ne consomme que l'espace réellement écrit sur l'hôte (~12 Go au départ), grandissant jusqu'au plafond de 80 Go.

Taille Fixe : Réquisitionne immédiatement 80 Go réels. À réserver aux serveurs de production à forte charge de base de données.

MODULE 02

Firmware Virtuel : UEFI, TPM 2.0 & Dépannage EFI Shell

Windows 11 rompt définitivement avec le BIOS hérité (Legacy BIOS / MBR). L'installation exige obligatoirement un environnement UEFI 64-bit natif avec partitionnement de disque GPT (GUID Partition Table).

Les composants obligatoires dans VirtualBox 7.0+

  • Activer EFI (Special OSes only) : Cette case doit être formellement cochée dans l'onglet Système > Carte mère. En son absence, l'image ISO ne démarre pas.
  • TPM virtuel (Trusted Platform Module) : Sélectionner la version 2.0 dans le menu déroulant. VirtualBox émule un coprocesseur cryptographique sécurisé pour stocker les clés BitLocker et l'intégrité de la plateforme.
  • Secure Boot : Activer le démarrage sécurisé pour garantir que seuls les chargeurs de démarrage signés par Microsoft sont autorisés à s'exécuter.
INCIDENT RÉCURRENT DU LAB

L'Écran Jaune « EFI Interactive Shell »

Symptôme : Au démarrage de la VM, l'écran reste bloqué sur une invite de commande jaune Shell> au lieu de charger l'installateur Windows.

Cause : Le message « Press any key to boot from CD or DVD... » n'a pas été validé dans les 5 secondes imparties. L'UEFI a tenté de booter sur le disque dur VDI encore totalement vierge et a basculé sur le shell de secours.

// PROCÉDURE DE DÉPANNAGE EN 3 ÉTAPES :
1. Saisir : exit puis appuyer sur [Entrée]
2. Dans l'interface du BIOS VirtualBox, sélectionner : Boot Manager
3. Sélectionner l'entrée du lecteur optique virtuel (CD/DVD ISO)
MODULE 03

Contournements Systèmes : Registre LabConfig & OOBE\BYPASSNRO

En environnement de test, d'analyse forensique ou sur des ordinateurs de laboratoire dépourvus de connexion réseau opérationnelle, deux verrous imposés par Microsoft doivent être neutralisés avec précision.

CONTOURNEMENT MATÉRIEL

Le Registre LabConfig (Bypass TPM & RAM)

Lorsque l'installeur affiche le message bloquant : « Ce PC ne répond pas actuellement à la configuration système requise pour Windows 11 ».

  1. Presser simultanément Shift + F10 (ou Maj + F10) pour ouvrir la console d'urgence Windows PE sous le compte NT AUTHORITY\SYSTEM.
  2. Taper regedit et valider par Entrée.
  3. Naviguer jusqu'à la clé :
    HKEY_LOCAL_MACHINE\SYSTEM\Setup
  4. Créer une nouvelle clé nommée : LabConfig
  5. Créer les valeurs DWORD 32 bits suivantes avec la valeur 1 :
    • BypassTPMCheck = 1
    • BypassSecureBootCheck = 1
    • BypassRAMCheck = 1
    • BypassCPUCheck = 1
  6. Fermer Regedit et CMD, cliquer sur la flèche de retour en haut à gauche de l'installeur : l'installation se débloque immédiatement.
CONTOURNEMENT RÉSEAU

Bypass OOBE : Forcer le Compte Local

Lors de la phase « Out-Of-Box Experience », Microsoft bloque le processus si aucun réseau actif n'est présent et tente de forcer la création d'un compte Cloud Microsoft (@outlook.com).

Pourquoi refuser le compte en ligne en Lab ?
  • Autonomie complète : Démarrage direct sans dépendance de connectivité cloud.
  • Dossier utilisateur propre : Crée C:\Users\AdminLab au lieu des 5 premières lettres imposées par un email.
  • Pas de synchronisation forcée : Neutralise le rapt des dossiers Bureau et Documents par OneDrive.
// Sur l'écran « Connectons-nous à un réseau », taper Shift+F10 :
C:\Windows\system32> OOBE\BYPASSNRO

Le PC redémarre instantanément. Au retour sur l'écran réseau, le lien « Je n'ai pas Internet » apparaît. Cliquer ensuite sur « Continuer avec l'installation limitée » pour créer un compte administrateur local indépendant.

MODULE 04

Pilotes Paravirtualisés : Guest Additions & Sysprep

Une machine virtuelle fraîchement installée est isolée et bridée : résolution d'écran figée en 1024×768 sans accélération matérielle WDDM, absence d'intégration de la souris, presse-papiers scellé et incapacité de transférer des scripts. Les Guest Additions fournissent la couche de pilotes paravirtualisés indispensable.

Déploiement pas-à-pas des Guest Additions

  1. Dans la barre de menus VirtualBox de la VM : Périphériques > Insérer l'image CD des Additions invité...
  2. Dans Windows 11, ouvrir l'Explorateur de fichiers (Win + E) et se rendre dans Ce PC.
  3. Ouvrir le lecteur CD virtuel contenant les additions.
  4. Faire un clic droit sur VBoxWindowsAdditions.exe et sélectionner « Exécuter en tant qu'administrateur ».
  5. Valider l'installation des pilotes de périphériques d'affichage Oracle WDDM et de bus système.
  6. Cocher « Reboot now » pour redémarrer la machine et charger les pilotes dans le noyau NT.
  7. Après redémarrage, activer dans Périphériques :
    • Presse-papiers partagé : Bidirectionnel
    • Glisser-déposer : Bidirectionnel
    • Dossiers partagés : Montage automatique d'un répertoire hôte
INDUSTRIALISATION DU POSTE

Sysprep & Clones Liés

Pour déployer plusieurs machines de lab sans réinstaller le système :

C:\Windows\System32\Sysprep\sysprep.exe /generalize /oobe /shutdown

La commande Sysprep réinitialise le SID (Security Identifier) unique. Vous pouvez ensuite créer des Clones Liés (Linked Clones) dans VirtualBox, économisant des dizaines de gigaoctets en partageant le disque parent en lecture seule.

MODULE 05

Déploiement Physique : Clean Install via Clé USB

Sur une machine physique (PC assemblé neuf ou réinstallation complète de poste de travail), la méthode officielle Microsoft repose sur un support amovible amorçable configuré via l'outil Media Creation Tool.

PHASE 1 : PRÉREQUIS MATÉRIELS

Le Choix du Support USB

• Clé USB 3.0 / 3.1 / 3.2 recommandée (connecteur bleu). Éviter l'USB 2.0 qui ralentit considérablement la copie.
• Capacité minimale : 8 Go (16 Go ou 32 Go vivement recommandé).
• Formatage automatique en FAT32 / GPT compatible firmware UEFI physique.

PHASE 2 : L'AMORÇAGE

Le Boot Menu Temporaire

• Règle d'or du technicien : Ne pas modifier l'ordre de démarrage permanent du BIOS.
• Tapoter la touche du Boot Menu temporaire (F11 ou F12 selon la carte mère, F8 sur Asus).
• Sélectionner le préfixe « UEFI : NomDeLaCléUSB ». Après le premier reboot, le SSD prend le relais sans reboucler sur la clé.

PHASE 3 : HYGIÈNE PILOTES

Pilotes Constructeur vs Windows

• Vérifier le Gestionnaire de périphériques (devmgmt.msc) : aucun triangle jaune.
• Installer le pilote GPU dédié officiel (NVIDIA Studio/Game Ready, AMD Adrenalin).
• Paramétrer le taux de rafraîchissement d'écran en Hertz maximal dans les paramètres avancés d'affichage.

PROCÉDURE QUALITÉ POST-DÉPLOIEMENT

Checklist Officielle : Validation du Poste Déployé

Points de contrôle obligatoires avant la livraison d'un poste Windows 11 en production ou en laboratoire d'analyse.

CONFORMITÉ DU POSTE
0% (0/8)
1. Compte Administrateur Local & Confidentialité

Session créée sans dépendance de compte Microsoft en ligne (@outlook), répertoire utilisateur propre dans C:\Users\Nom et télémétrie restrictive configurée.

2. Intégrité du Firmware & Table de Partitionnement GPT

Système démarré en mode UEFI natif (vérifié via msinfo32 : Mode BIOS = UEFI), Secure Boot actif et partitionnement GPT sans vestige MBR.

3. Gestionnaire de Périphériques Vierge (devmgmt.msc)

Absence formelle de tout triangle jaune d'avertissement ou de périphérique inconnu dans l'arbre matériel.

4. Pilotes Paravirtualisés (Guest Additions sous VirtualBox)

Package VBoxWindowsAdditions.exe exécuté en admin, pilote graphique WDDM opérationnel avec adaptation dynamique de la résolution d'écran à la fenêtre hôte.

5. Canaux d'Échange Activés (Presse-papiers & Glisser-Déposer)

Réglage dans le menu Périphériques de VirtualBox sur « Bidirectionnel » validé par un copier-coller effectif entre l'hôte et la VM.

6. Dossiers Partagés avec Montage Automatique

Lecteur réseau persistant monté dans l'Explorateur (ex. lecteur Z:) pour l'échange de scripts et payloads sans passer par le réseau LAN.

7. Mises à Jour Cumulatives Windows Update à 100%

Exécution complète de Windows Update jusqu'à l'obtention du statut « Vous êtes à jour » pour patcher les vulnérabilités initiales de l'image ISO.

8. Hygiène Logicielle & Optimisation Fréquence Écran (Hz)

Aucun antivirus tiers intrusif installé (Windows Defender actif suffit), fréquence de rafraîchissement d'affichage vérifiée à son maximum dans les options avancées.
